プライバシーポリシー

更新日: 2026年10月5日

かんたんレジは、開発者による個人情報の収集、広告配信、利用状況の追跡を行いません。アプリの使用にアカウント登録は必要ありません。

商品名・価格・確定した会計の明細と日時は端末内に保存します。アプリから開発者のサーバーへ送信する機能はありません。

利用者がCSVを書き出す場合、利用者が選んだ保存先や共有先に売上明細が渡されます。保存先・共有先のサービスによる取扱いには、そのサービスの規約とプライバシーポリシーが適用されます。

端末のバックアップ設定によって、アプリの保存データがOSのバックアップに含まれる場合があります。バックアップの取扱いは利用するOS・サービスの設定に従います。

端末内のアプリデータを削除すると、アプリに保存された商品と会計の記録が削除されます。すでに書き出したCSVやバックアップは別途管理してください。

お問い合わせ: GitHub Issues（GitHub アカウントが必要です）。投稿は公開されます。個人情報や売上明細を投稿しないでください。
