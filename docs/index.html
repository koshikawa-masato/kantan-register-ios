かんたんレジスター

対面販売の会計を、シンプルに。

iPhone・iPad で商品選択から釣り銭計算、売上の記録まで。インターネット接続やログインなしで使える無料のレジアプリです。

主な機能

  • 商品名と価格の登録・編集
  • 数量変更と商品取消
  • お客様側に向けた商品一覧と合計表示
  • 預かり額・釣り銭の計算
  • 売上保存、日報、CSV 書き出し

iOS・iPadOS 17 以降に対応。カード決済の処理機能はありません。

App Store 公開準備中です。
